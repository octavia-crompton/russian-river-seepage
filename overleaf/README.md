# overleaf/

Manuscript source for the Russian River seepage paper.

| Folder | Purpose |
|---|---|
| `draft/` | Working copy — make edits here |
| `mirror/` | Synced mirror of the Overleaf project |
| `snapshot_2026-03-05/` | Frozen snapshot (2026-03-05) — do not edit |

## Workflow

1. Edit in `draft/`.
2. When ready, copy to `mirror/` and push/sync to Overleaf.
3. Before major revisions, create a new `snapshot_<date>/` folder.
